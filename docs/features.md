# 機能要件・ユースケース - レシピ管理アプリ

[要件定義書](./requirements.md) の詳細ドキュメント。

## 1. 機能要件

### 1.1 レシピのCRUD

- [ ] レシピ一覧表示
- [ ] レシピ詳細表示
- [ ] レシピ新規登録
- [ ] レシピ編集
- [ ] レシピ削除

### 1.2 検索・カテゴリ分類

- [ ] カテゴリによる絞り込み（例: 和食 / 洋食 / 中華 / デザート など）
- [ ] キーワード検索（料理名を対象）

## 2. ユースケース・操作フロー

### 2.1 想定ユーザー

- 自分（開発者本人）のみ。ログイン機能はないため、URLを知っていれば誰でも閲覧・編集できる（詳細は[非機能要件 - セキュリティ要件](./non_functional.md#2-セキュリティ要件)を参照）。

### 2.2 主要ユースケース

| No | ユースケース | 目的 |
|---|---|---|
| UC1 | レシピを新規登録する | 作った料理のレシピを記録する |
| UC2 | レシピ一覧から探す | 過去に登録したレシピを見返す |
| UC3 | カテゴリ・キーワードで絞り込む | 作りたい料理のジャンルから探す |
| UC4 | レシピ詳細を見ながら調理する | 材料・手順を確認しながら実際に作る |
| UC5 | レシピを編集する | 分量や手順の記録ミスを直す |
| UC6 | レシピを削除する | 不要になったレシピを整理する |

### 2.3 操作フロー（例: UC1 レシピを新規登録する）

```
[一覧画面]
   │ 「新規登録」ボタンをクリック
   ▼
[登録編集フォーム画面（新規モード）]
   │ 料理名・材料・手順・カテゴリ等を入力
   │ 「保存」ボタンをクリック
   ▼
  入力チェックOK？
   │Yes                │No
   ▼                   ▼
[一覧画面に遷移]      [フォーム画面にエラー表示]
（登録したレシピが     （該当項目にエラーメッセージ、
 一覧に反映される）     未入力/不正値の項目にフォーカス）
```

### 2.4 操作フロー（例: UC3 → UC4 検索して詳細を見る）

```
[一覧画面]
   │ カテゴリを選択 or キーワードを入力
   ▼
一覧が絞り込み結果に更新される
   │ 見たいレシピをクリック
   ▼
[詳細画面]
（材料・手順・カテゴリ・タグ等を表示）
```
