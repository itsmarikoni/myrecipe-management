# myrecipe-management

個人用のレシピ管理アプリ。自分で作った・作りたい料理のレシピを登録し、カテゴリやキーワードで検索できる。

カリキュラム課題として、技術スタックを変更した上で一から設計・実装を行っている。

## アプリ概要

| 項目 | 内容 |
|---|---|
| アプリ名 | myrecipe-management |
| 目的 | 個人が自分のレシピを記録・検索できるアプリ |
| 想定ユーザー | 個人（自分専用） |
