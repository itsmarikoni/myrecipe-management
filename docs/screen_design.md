# 画面・UI要件 - レシピ管理アプリ

[要件定義書](./requirements.md) の詳細ドキュメント。

## 1. 画面一覧

| No | 画面名 | 概要 |
|---|---|---|
| S1 | レシピ一覧画面 | 登録済みレシピの一覧表示、検索・カテゴリ絞り込み |
| S2 | レシピ詳細画面 | 1件のレシピの詳細（材料・手順等）を表示 |
| S3 | レシピ登録編集フォーム画面 | レシピの新規登録・編集を行う（新規/編集は同一画面を共用） |

## 2. 画面遷移図

```
                 ┌────────────────────┐
                 │   S1: レシピ一覧    │
                 │（検索・カテゴリ絞込） │
                 └─────────┬──────────┘
             「新規登録」│      │クリック（1件を選択）
                        ▼      ▼
        ┌───────────────────┐ ┌───────────────────┐
        │ S3: 登録編集フォーム │ │  S2: レシピ詳細    │
        │     （新規モード）   │ │                   │
        └─────────┬─────────┘ └─────────┬─────────┘
                   │保存                 │「編集」クリック
                   ▼                    ▼
              [S1へ戻る]        ┌───────────────────┐
                                │ S3: 登録編集フォーム │
                                │    （編集モード）    │
                                └─────────┬─────────┘
                                          │保存
                                          ▼
                                    [S2 or S1へ戻る]

  S2から「削除」をクリック → 確認ダイアログ → OKでS1へ遷移
```

## 4. UI要素の振る舞い

| 要素 | 振る舞い |
|---|---|
| 検索ボタン | クリックでキーワード・カテゴリ条件を一覧に反映（ページ再読込ではなく一覧部分のみ更新） |
| 新規登録ボタン | S3画面（新規モード・空フォーム）に遷移 |
| レシピカード | クリックでS2画面（該当レシピの詳細）に遷移 |
| 編集ボタン（S2） | S3画面（編集モード・既存値が入力済みの状態）に遷移 |
| 削除ボタン（S2） | 確認ダイアログ（「本当に削除しますか？」）を表示し、OKでAPIに削除リクエスト送信後S1へ遷移 |
| 保存ボタン（S3） | 入力チェック実施後、問題なければAPIに登録/更新リクエストを送信 |
| 材料/手順の＋追加ボタン | 入力欄を1行追加する（複数行入力を想定） |

## 5. エラー時の表示

| ケース | 表示内容 |
|---|---|
| 必須項目未入力のまま保存 | 該当項目の直下に赤字でエラーメッセージを表示し、保存処理を中断する |
| 数値項目に不正な値（文字列等）を入力 | 該当項目にエラーメッセージを表示（例:「数値を入力してください」） |
| API通信エラー（サーバーエラー・通信断） | 画面上部に共通のエラーメッセージを表示（例:「通信エラーが発生しました。時間をおいて再度お試しください」） |
| 検索結果が0件 | 一覧部分に「該当するレシピが見つかりません」を表示 |
| 存在しないレシピIDで詳細画面にアクセス | 「レシピが見つかりません」画面を表示し、一覧へ戻る導線を用意する |
